# Túttt v0.8.38 — Kết quả kiểm tra dependency và native build

**Ngày:** 12/11/2026 · **Nguồn:** v0.8.37 · **Phạm vi:** độ tin cậy của cổng dependency/Expo/TypeScript; không sửa giao diện.

## Đã sửa

- `scripts/native_dependency_integrity.mjs`: kiểm tra npm lockfile v3, các gói direct đã phân giải, phiên bản thực tế của từng package đã cài, phân loại lỗi npm.
- `scripts/verify_native.mjs`: npm lockfile-only strict → `npm ci --strict-peer-deps` → `npm ls` → Expo SDK check → Expo Doctor → `tsc --noEmit` theo đúng thứ tự. Thất bại cài đặt vẫn BLOCKED dù có node_modules cũ.
- `scripts/doctor_native.mjs`: bổ sung kiểm tra lockfile đã phân giải và cây packages đã cài, không chỉ kiểm tra có thư mục `expo`.
- `tests/native_dependency_integrity_v0838.test.js`: thêm sáu bài hồi quy cho lockfile giả/thiếu, dependency lệch, nguồn gói, lỗi mạng và cổng sẵn sàng.
- Đồng bộ metadata v0.8.38 và tài liệu chạy trên máy phát triển.
