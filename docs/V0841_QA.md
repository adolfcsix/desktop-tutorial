# Túttt v0.8.41 — Báo cáo nghiệm thu

Ngày: 12/11/2026. Nguồn: `TUTTT_V0_8_40.zip` (460 mục). Giao diện và hệ màu giữ nguyên; không thêm nút hay hoạt ảnh.

## Đã triển khai

- Tách hai trạng thái nghiệm thu Native: `dependencyGate` / `technicalGate` và `deviceConfigGate`; không gộp lỗi thiếu API/ID với lỗi TypeScript.
- Bổ sung kiểm tra `expo config --type prebuild --json` sau khi đã xác thực thư viện, để phát hiện lỗi resolution plugin trước khi tạo development build.
- Preflight Node trước khi chạy cài dependency, tránh cố tải thư viện trên runtime không tương thích.
- Bổ sung `--device` để buộc cấu hình thiết bị phải đạt trước khi coi quy trình build sẵn sàng; không có secrets trong gói.
- Thêm 6 bài kiểm thử mới và cập nhật hồi quy cũ tương ứng.
- Đồng bộ phiên bản root, backend, mobile, HTML thành v0.8.41; xuất lại bản HTML độc lập.

## Lệnh để tiếp tục trên máy phát triển có mạng

```bash
npm run doctor:native
npm run verify:native -- --install
npm run verify:native -- --device
```

Phải kiểm tra `dependencyGate=PASS` và `deviceConfigGate=PASS` trước khi tạo build. **Ngay cả khi cả hai đạt, vẫn chưa chứng minh APK/IPA và media thật hoạt động**; cần nghiệm thu thiết bị riêng. Không dùng `--force`/`--legacy-peer-deps`, không tạo lockfile giả, không đưa LiveKit secret vào ứng dụng.
