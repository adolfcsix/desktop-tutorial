# Túttt v0.8.37 — Báo cáo nghiệm thu

**Ngày:** 12/11/2026. **Nguồn:** v0.8.36. **Phạm vi:** chuẩn hóa kiểm tra dependency và tương thích Expo SDK 58/LiveKit, sửa prop React Native bị loại bỏ, không thay đổi UI/UX Live/PK.

## Mã đã thay đổi

- `mobile/App.tsx`: bỏ prop `StatusBar.backgroundColor` đã bị loại bỏ trong React Native 0.88.
- `mobile/package.json`: thêm `expo-doctor` 1.21.6, script `sdk:check`, ghim công cụ TypeScript và React type. Giữ React/React DOM/RSC cùng phiên bản 19.3.0.
- `scripts/doctor_native.mjs`: thêm kiểm tra peer pins, nhận dạng API RN 0.88 bị loại và tính nhất quán root của lockfile npm v3.
- `scripts/verify_native.mjs`: bổ sung cổng xác nhận cài dependency, Expo SDK check, Expo Doctor, TypeScript; báo BLOCKED khi chưa đủ điều kiện.
- `tests/native_dependency_gate_v0837.test.js`: thêm 6 ca hồi quy.
- Đồng bộ version 0.8.37 ở root, backend, mobile, Expo và HTML; bổ sung tài liệu `docs/NATIVE_BUILD_VERIFICATION_V0837.md`.
