# Túttt v0.8.32 — Menu Live hợp nhất, có phân quyền

**12/11/2026 · Nâng trực tiếp từ v0.8.31.** Phạm vi thực thi: prototype web, React Native source, API adapter báo cáo, CSS, tài liệu và bài kiểm thử. Không thay logo Túttt, Ivory/Espresso, ghép media, luật PK hoặc điểm do máy chủ xác nhận.

## Thay đổi

1. **Một menu `•••` cố định ở header Voice/Cam, kể cả lúc PK.** Bỏ dấu `•••` trên đấu trường PK ở web/Native và bỏ nút quản lý phòng thứ hai ở Cam/Native.
2. **Ba chức năng không chồng lặp:** Quản lý phòng (chỉ role host/phó phòng với Live roster khả dụng), PK & kết quả (chỉ khi có trận/hiển thị kết quả), Báo cáo phòng (mọi người). Nút PK bên ngoài giữ chức năng **khởi tạo/nhận lời mời** trước trận. Web Cam kiểm tra quyền ngay ở giao diện và tại handler; server tiếp tục quyết định quyền cuối cùng. Web Voice chưa có panel quản lý tương đương Native, nên không hiển thị nút quản lý Voice thiếu chức năng.
3. **Báo cáo mobile đã nối API `/api/reports` hiện hữu:** validate lý do 8–250 ký tự, gửi yêu cầu thật, xử lý trạng thái, lỗi và xác nhận. Khi không kết nối backend thì không giả lập gửi thành công. Giao diện không tự hứa hẹn có đội kiểm duyệt tự động.
4. **Không bổ sung menu/trang chuyển động:** loại bỏ 23 bộ chọn CSS của hai nút đã xóa trong 11 stylesheet hiện hữu; không thêm CSS file.
5. **Điều hướng và kiểm thử cũ:** sửa bài kiểm thử legacy còn cố bấm PK `•••` tại đấu trường để đi qua menu chung thay vì xóa kiểm thử hành vi.
