# Túttt v0.8.31 — Giao diện tĩnh hơn, ít nút giả hơn

Ngày: **12/11/2026**. Nâng từ **v0.8.30**. Phạm vi: prototype web, source React Native, bản xem trước HTML độc lập. **Không xác nhận** truyền media hai thiết bị thật hoặc build Native.

## Đã chỉnh trực tiếp

1. Bỏ nút **Top 3** khỏi phòng Voice và Cam khi chưa có dữ liệu lịch sử giao dịch được xác thực. Bỏ modal hỗ trợ giả và CSS không sử dụng. Mobile bỏ Top 3 chưa có backend. Không thay đổi API quà tặng, luật cổ vũ hoặc việc quản trị phòng.
2. Bỏ nút **Quyền riêng tư** trên Hồ sơ Native vì thực chất điều hướng tới Cài đặt giống nút ngay bên cạnh; nội dung quyền riêng tư vẫn thuộc Cài đặt.
3. Bỏ các nhịp nhấp nháy PK không có thông tin (dấu Live, cảnh vào sân khấu, trang trí lấp lánh, đồng hồ nhấp nháy). Loại bỏ đếm chạy từng số khi điểm PK thay đổi; số được hiển thị tức thời theo trạng thái đã đồng bộ, thanh tỷ lệ vẫn cập nhật. Điều này tránh nhiễu, không thay đổi server-authoritative scoring.
4. Giảm biên độ rung avatar đang nói khi có **bằng chứng mic thực**; giữ trạng thái viền xanh, mic gạch chéo khi tắt, và tôn trọng reduced-motion của thiết bị. Không thêm cài đặt hoặc nút giảm chuyển động.
5. Đồng bộ phiên bản 0.8.31 ở gói nguồn, mobile/app metadata, web và API health; xuất HTML standalone từ cùng source.
