## Các điều kiện còn thiếu trước khi nghiệm thu Native

- Máy build có thể tải npm registry, sau đó tạo **lockfile thật** qua npm và chạy `npm ci --strict-peer-deps`, Expo Doctor, `expo install --check`, `tsc --noEmit`.
- Đặt app IDs thuộc quyền sở hữu; URL API staging HTTPS có thể truy cập từ điện thoại. Backend cấp LiveKit token từ máy chủ, không đặt API secret trong client.
- Có cấu hình ký ứng dụng, Android SDK/JDK và iOS/Xcode/EAS phù hợp, tối thiểu hai thiết bị cho thử media, camera, Bluetooth và chuyển mạng.

**Kết luận:** Có thể bàn giao mã nguồn v0.8.39 và UI HTML để xem/kiểm thử offline. Chưa thể tuyên bố ứng dụng Native build-ready hoặc media hoạt động ổn định trên Android/iOS thật.
