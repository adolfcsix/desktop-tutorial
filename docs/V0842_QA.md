# Túttt v0.8.42 — Báo cáo nghiệm thu

**Ngày thực hiện:** 13/11/2026. **Nguồn:** `TUTTT_V0_8_41.zip`. **Mục tiêu:** nghiệm thu dependency/Expo trung thực, không thêm UI.

## Thay đổi thực hiện

1. Sửa phân loại `deviceConfigGate` trong `scripts/verify_native.mjs`: trước đó phụ thuộc gián tiếp vào cảnh báo lockfile/`node_modules` từ `staticReport.status`; nay chỉ xét khai báo Android/iOS ID, API, media permissions, EAS và dev client.
2. Bổ sung `configAuditGate` thể hiện toàn bộ báo cáo cấu hình riêng, giữ `dependencyGate` / `technicalGate` cho kết quả npm/Expo/TypeScript. Đã cấu hình đủ thiết bị vẫn **không** làm dependency gate thành PASS.
3. Nếu Android/iOS ID sai khiến Expo config throw, trả JSON `deviceConfigGate=FAIL` và bước lỗi thay vì crash không có báo cáo.
4. Cổng kiểm tra dependency từ chối prerelease cài đặt trái với semver khai báo ổn định (`~`, `^`).
5. `qa:release` lưu riêng `nativeReadiness` trong báo cáo, không biến các ca QA offline thành tuyên bố đã build Native.
6. Bổ sung 6 bài hồi quy, đồng bộ root/server/mobile/HTML lên v0.8.42. Giữ nguyên bố cục, logo, các nút và chuyển động Voice/Cam/PK.

## Bước tiếp theo trên máy có mạng

```bash
cd mobile
npm install --package-lock-only --strict-peer-deps --ignore-scripts --no-audit --no-fund
npm ci --strict-peer-deps --no-audit --no-fund
cd ..
npm run verify:native -- --device
```

Chỉ bắt đầu build Expo khi `dependencyGate=PASS`, `deviceConfigGate=PASS` và đã đặt đúng ID/API do bạn sở hữu. Sau đó nghiệm thu riêng development build Android/iOS, hai điện thoại với SFU và chuyển Wi-Fi/4G/Bluetooth. Không sửa kết quả hoặc tạo lockfile giả để lách cổng kiểm tra.
